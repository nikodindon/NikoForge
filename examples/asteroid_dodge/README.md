# 🚀 Asteroid Dodge

Un jeu d'arcade simple et amusant créé avec Python et Pygame.

## 📋 Prérequis

- Python 3
- Pygame

## 🚀 Installation

1. Installez Pygame :
   ```bash
   pip install pygame
   ```

2. Lancez le jeu :
   ```bash
   python main.py
   ```

## 🎮 Comment jouer

- **↑ ↓ ← →** : Déplacer le vaisseau
- **ESPACE** : Redémarrer le jeu après une défaite

## 📁 Structure

- `main.py` : Point d'entrée et logique principale
- `player.py` : Classe du vaisseau joueur
- `asteroid.py` : Classe des astéroïdes
