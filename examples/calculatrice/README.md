# Projet Calculatrice

Une calculatrice simple en Python avec une interface en ligne de commande.

## Structure du projet

- `main.py` : Point d'entrée principal du programme.
- `operations.py` : Contient les fonctions mathématiques de base.

## Installation

Aucune installation nécessaire. Python 3 est requis.

## Utilisation

1. Clonez ce dépôt ou téléchargez les fichiers.
2. Ouvrez un terminal dans le répertoire `calculatrice`.
3. Exécutez le programme :

```bash
python main.py
```

4. Suivez les instructions à l'écran pour effectuer des calculs.
