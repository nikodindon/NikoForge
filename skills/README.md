# Skills pour NikoForge

Ce répertoire contient des instructions réutilisables pour NikoForge.

Chaque skill est un fichier Markdown qui peut être chargé par l'agent pour spécialiser son comportement.

## Structure

```
skills/
├── python-development.md
├── web-development.md
├── debugging.md
└── ...
```

## Comment créer un skill

1. Crée un fichier Markdown dans ce répertoire
2. Décris les bonnes pratiques, conventions et workflows
3. Utilise des sections claires avec des titres
4. Inclue des exemples de code si nécessaire

Voir `python-development.md` pour un exemple complet.
